Abrir proyecto Python

Abre una carpeta local o lee el proyecto directamente por SSH.

Por SSH, el análisis se ejecuta en memoria en el servidor. Las fuentes se leen bajo demanda y no se guardan en el índice local. No importa módulos ni ejecuta el proyecto.

Las evaluaciones del modelo son predictivas. Los ensayos son registros separados con su procedencia. Una métrica elevada o la ausencia de un informe de tests no bastan para pintar un componente de rojo.

Verde: condiciones favorables. Amarillo: fricción localizada. Naranja: obstáculos importantes. Rojo: obstáculos graves demostrados. Gris: sin evaluación suficiente.
